# שבעה ימים

משחק דו-מימדי קצר בדפדפן. אתה איש רגיל עם שגרה קבועה: לצחצח שיניים, להתלבש, לנסוע לעבודה, לעבוד, לחזור הביתה, לאכול, ארוחת ערב, שוב לצחצח, ולישון.
כל יום משהו קטן משתבש קצת יותר. ביום השביעי הוא כבר לא בסדר בכלל.

## איך משחקים

פותחים את `index.html` בדפדפן. אין צורך בהתקנה או בשרת.

- `←` `→` או `A` `D` ללכת
- `E`, רווח או Enter לעשות דברים ולהתקדם בדיאלוג
- בטלפון מופיעים כפתורי מגע

קיצור לבדיקות: להוסיף לכתובת `#day5` (או כל יום 1–7) כדי להתחיל ישר ביום הזה.

## מה קורה בכל יום (ספוילרים)

| יום | מה משתבש |
|---|---|
| 1 | כלום. יום רגיל. |
| 2 | השעון מראה 07:60, דני אומר הכול פעמיים, הצבעים דוהים. |
| 3 | אחרי הצחצוח אתה פשוט מוצא את עצמך בעבודה. המשימות של הבוקר נעלמות. |
| 4 | ההשתקפות מאחרת, אנשים ברחוב עומדים ובוהים, ובמשרד כל העובדים נעלמים. |
| 5 | הדלת הראשית מחזירה לחדר השינה, לאנשים אין פנים, הצלחת ריקה. |
| 6 | השמש לא שוקעת, השליטה מתהפכת, המראה מדברת, ורשימת המשימות פונה אליך. |
| 7 | כל המשימות הן "לצחצח שיניים", הבית מתעקם, כולם הם אתה, והמיטה בורחת. |

הכול בקובץ HTML אחד: Canvas ו-JavaScript בלי ספריות, וסאונד מסונתז עם Web Audio.
