# שבעה ימים

משחק דו-מימדי קצר בדפדפן. אתה איש רגיל עם שגרה קבועה: לצחצח שיניים, להתלבש, לנסוע לעבודה, לעבוד, לחזור הביתה, לאכול, ארוחת ערב, שוב לצחצח, ולישון.
כל יום משהו קטן משתבש קצת יותר. ביום השביעי הוא כבר לא בסדר בכלל. ואז מגיע יום שמיני, ויום תשיעי שבו מתברר לאן הנשמה שלו הולכת.

## שני מצבים

במסך הפתיחה בוחרים:

- **מצב מפחיד**: 9 ימים. השגרה מתפרקת לאט, עד שהוא משתגע. זה המשחק המקורי.
- **מצב מצחיק**: 7 ימים, קליל יותר. אותה שגרה, אבל כל יום קורה משהו מטופש יותר.

|---|---|
| 1 | השעון המעורר נוחר, ודני מספר בדיחת אבא. |
| 2 | יום שיער רע, ובשפופרת של משחת השיניים יש מיונז. |
| 3 | חתול כתום מופיע ולא עוזב. בעבודה מקלידים MEOW. |

| 5 | יום הפוך: הולכים אחורה, ההשתקפות רוקדת והשמיים ורודים. |

| 7 | מסיבת הפתעה! מתברר למה כל השבוע היה מוזר. |

## איך משחקים

פותחים את `index.html` בדפדפן. אין צורך בהתקנה או בשרת.

- `←` `→` או `A` `D` ללכת
- `E`, רווח או Enter לעשות דברים ולהתקדם בדיאלוג

### בטלפון

המשחק מזהה לבד אם משחקים במחשב או בטלפון/טאבלט, ומחליף מצב אם מתחילים פתאום להשתמש במקלדת או במגע.

- `◀` `▶` ללכת, `✋` לעשות דברים. אפשר גם פשוט לגעת בחפץ על המסך: הדמות תלך אליו ותשתמש בו.
- צחצוח: `◀` `▶` לסירוגין, או החלקה על המסך ימינה ושמאלה.
- עבודה: מופיעים ארבעה מקשי אותיות גדולים, ולוחצים על האות הנכונה.
- לאורך: המשחק בחלק העליון, רשימת המשימות והדיאלוג מתחתיו, והכפתורים בתחתית.
- לרוחב: המשחק על כל המסך והכפתורים בפינות. יש כפתור "מסך מלא" במסך הפתיחה.
- ברגעים המפחידים הטלפון רוטט (במכשירים שתומכים בזה).

קיצור לבדיקות: להוסיף לכתובת `#day5` (או כל יום 1–9) כדי להתחיל ישר ביום הזה, או `#heaven` / `#hell` כדי לראות ישר את אחד הסופים. במצב המצחיק: `#funny1` עד `#funny7`.

### איך מגיעים לגן עדן

צריך לשים לב לכל דבר, כל יום: לגשת לכל חפץ ולכל אדם ולדבר איתם (E או נגיעה), כולל הדלתות, תחנת האוטובוס והאנשים במשרד. על הפתק יש מונה "שמתי לב: X/Y". רק מי שמילא אותו בכל אחד מהימים 1–8 מגיע לגן עדן, וכל השאר מגיעים לגיהנום.

הכול בקובץ HTML אחד: Canvas ו-JavaScript בלי ספריות, וסאונד מסונתז עם Web Audio.
